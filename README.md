# 🚀 Modern Go Learning Path

Kurikulum belajar **Golang dari dasar sampai membangun REST API + Database + Project**.

---

## 🎯 Target Pembelajaran

Setelah menyelesaikan kurikulum ini, kamu diharapkan mampu:

* Memahami syntax dan konsep dasar Go
* Membuat program dengan struktur yang rapi
* Menggunakan Struct, Interface, Pointer, Map, Array, dan Slice
* Menangani error dengan idiomatic Go
* Membuat Package dan Module
* Memahami concurrency dengan Goroutine dan Channel
* Membuat HTTP Server
* Membuat REST API
* Terhubung ke Database
* Membangun project backend Go secara utuh
